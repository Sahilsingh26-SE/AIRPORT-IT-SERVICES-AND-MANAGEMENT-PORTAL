# ✈️ Airport IT Service & Asset Management Portal - Frontend

A modern React-based frontend for an Airport IT Service & Asset Management Portal. The application provides a clean dashboard for managing IT support tickets, assets, users, and system settings.

## Features

* Secure Login & Signup
* Dashboard with statistics
* Raise IT Support Tickets
* Ticket Management
* Asset Management
* User Management
* Responsive UI
* Dark Mode Support

## Tech Stack

* React.js
* React Router
* Axios
* Lucide React
* CSS

## Installation

```bash
npm install
npm run dev
```

The frontend runs on:

```
http://localhost:5173
```
